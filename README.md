# Customer Retention, Revenue & Behavioral Analytics Using Python

## Project Overview

This project analyzes 5,000+ customer transactions using Python to understand revenue performance, customer purchasing behavior, repeat purchases, and retention patterns.

The analysis converts raw transaction data into meaningful business insights that can support customer retention and revenue-growth strategies.

## Business Objectives

- Analyze overall revenue and sales performance
- Understand customer purchasing behavior
- Identify repeat and one-time customers
- Analyze customer retention patterns
- Identify high-value customers
- Compare products, categories, regions, customer segments, and sales channels
- Generate actionable business recommendations

## Dataset

The dataset contains 5,000 customer transaction records with information about:

- Order details
- Customer information
- Product and category
- Quantity and pricing
- Discounts
- Payment methods
- Sales channels
- Order status
- Customer purchase history

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- JupyterLab

## Analysis Performed

The project includes:

- Data loading and understanding
- Data cleaning and validation
- Revenue calculations
- Customer analysis
- Product and category analysis
- Regional analysis
- Sales channel analysis
- Repeat customer analysis
- Retention analysis
- Monthly revenue trends
- Business insights and recommendations

## Key Findings

- The dataset contains 5,000 orders and 858 unique customers.
- Approximately 81.47% of customers are repeat customers.
- Net revenue is approximately ₹18.55 crore.
- Revenue performance varies across products, regions, customer segments, and sales channels.
- The analysis identifies opportunities to improve customer retention and increase repeat purchases.
